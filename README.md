<h1 align="center">🧠 Hindu Vocabulary Bot</h1>
<p align="center">
  <b>AI-Powered Vocabulary Generator using UiPath Studio Web & OpenAI</b>
</p>

<hr>

<h2>📌 Overview</h2>
<p>
The <b>Hindu Vocabulary Bot</b> is an AI-powered automation project built using <b>UiPath Studio Web</b> 
and <b>OpenAI API</b>. It is designed to generate structured vocabulary content to support 
language learning and improve word knowledge efficiently.
</p>

<p>
The bot dynamically generates <b>Top 10 vocabulary words</b> categorized into 
<b>Easy, Medium, and Hard</b> levels, along with detailed linguistic information.
</p>

<hr>

<h2>🚀 Features</h2>
<ul>
  <li>📚 Generates <b>Top 10 vocabulary words</b> based on difficulty level</li>
  <li>🔤 Provides <b>Hindi pronunciation</b> for each word</li>
  <li>📖 Displays <b>meaning</b> of each word</li>
  <li>🔁 Includes <b>synonyms and antonyms</b></li>
  <li>⚡ Uses <b>OpenAI API</b> for dynamic and intelligent content generation</li>
  <li>🎯 Structured output using <b>HTML formatting</b> for better readability</li>
</ul>

<hr>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>UiPath Studio Web</b> – Automation workflow development</li>
  <li><b>OpenAI API</b> – AI-based content generation</li>
  <li><b>HTML</b> – Structured output formatting</li>
  <li><b>Prompt Engineering</b> – Ensuring consistent and high-quality responses</li>
</ul>

<hr>

<h2>⚙️ How It Works</h2>
<ol>
  <li>User selects difficulty level (Easy / Medium / Hard)</li>
  <li>Bot sends a structured prompt to OpenAI model</li>
  <li>Model generates vocabulary data in predefined HTML format</li>
  <li>Bot processes and displays the formatted output</li>
</ol>

<hr>

<h2>📊 Output Format</h2>
<p>Each generated word includes:</p>
<ul>
  <li>Word</li>
  <li>Hindi Pronunciation</li>
  <li>Meaning</li>
  <li>Synonyms</li>
  <li>Antonyms</li>
</ul>
